# 小六壬 Web 版

纯本地 HTML/CSS/JavaScript，适合直接部署到 GitHub Pages。

## 功能
- 顶部固定显示打开页面时的当前阳历时间。
- 默认立即显示当前阳历对应的农历日期、古代时辰和天/地/人三果位。
- 输入阳历 `YYYY.MM.DD.HH`，例如 `2025.12.11.21`，按 Enter 起盘。
- 历史起盘不会修改顶部当前阳历时间，只更新农历对照和卦象。
- 子时：23:00–00:59；丑时：01:00–02:59；依次至亥时 21:00–22:59。
- 起盘算法：天从大安起按农历月数；地从天位重新计 1 按农历日数；人从地位重新计 1 按时辰序号。

## GitHub Pages
将 `web` 目录内容发布到 Pages 的根目录即可。CSS、JS、PWA 缓存均为本地文件，不依赖 CDN。
